# Google Search Clone 🔍
**A CS50W Project 0: Front-end Web Development**

A front-end replica of Google Search, Google Image Search, and Google Advanced Search. This project focuses on UI/UX design using **HTML** and **CSS**, aiming to match Google's aesthetics and functionality.

## Features ✨
* **Main Search**: A functional search bar that redirects users to Google search results.
* **Image Search**: Dedicated page to search specifically for images.
* **Advanced Search**: Provides options for "all these words," "this exact word or phrase," "any of these words," and "none of these words," matching Google's advanced search logic.
* **I'm Feeling Lucky**: A button that takes users directly to the first search result (bypassing the results page).
* **Responsive Design**: Styled with CSS to be clean and aesthetically consistent with the original Google interface.

## Tech Stack 🛠️
* **HTML5**: For structuring the web pages.
* **CSS3**: For styling, including hover effects, centered layouts, and Google-style buttons.
